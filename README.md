# Personal Knowledge Assistant

A full-stack, AI-powered personal knowledge assistant that allows you to upload documents (PDFs) and chat with your own knowledge base using Retrieval-Augmented Generation (RAG).

Built with **Next.js 16**, **Vercel AI SDK v7**, **Supabase** (with `pgvector`), and **Groq** for blazing-fast inference.

## 🚀 Features

- **Retrieval-Augmented Generation (RAG)**: Chat with your own documents. The assistant chunks your PDFs, generates embeddings, and retrieves relevant context to answer your questions accurately.
- **Fast Inference with Groq**: Uses `llama-3.3-70b-versatile` via Groq for high-speed, high-quality responses.
- **Local Embeddings**: Uses HuggingFace Inference API (`sentence-transformers/all-MiniLM-L6-v2`) to generate 384-dimensional vector embeddings.
- **Vector Database**: Uses Supabase with `pgvector` to store and query embeddings efficiently using cosine similarity.
- **Conversation Persistence**: Chat history is saved in PostgreSQL, allowing you to revisit past conversations.
- **Beautiful UI**: Built with Tailwind CSS v4, GSAP, and standard Markdown rendering for code blocks.
- **State Management**: Uses Redux Toolkit for seamless client-side state handling.

## 🛠️ Tech Stack

- **Framework**: Next.js (App Router) & React 19
- **AI SDK**: Vercel AI SDK
- **LLM**: Groq (`llama-3.3-70b-versatile`)
- **Embeddings**: HuggingFace (`all-MiniLM-L6-v2`)
- **Database**: Supabase (PostgreSQL + pgvector)
- **Styling**: Tailwind CSS v4
- **State**: Redux Toolkit

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone <your-repo-url>
cd personal-knowledge-assistant
```

### 2. Install dependencies
```bash
npm install
# or
yarn install
# or
pnpm install
```

### 3. Set up Supabase
1. Create a new project on [Supabase](https://supabase.com).
2. Enable the `pgvector` extension in your database (can be done via the Supabase dashboard).
3. Run the SQL commands provided in `setup-db.sql` in the Supabase SQL Editor to create the `conversations` and `messages` tables.
4. **Important**: You also need to create the `chunks` table and the `match_chunks` function for vector search. Run the following SQL in your Supabase SQL Editor (as noted in `lib/supabase.ts`):

```sql
-- Enable the pgvector extension to work with embedding vectors
create extension if not exists vector;

-- Create the chunks table
create table if not exists public.chunks (
  id bigint generated by default as identity primary key,
  text text not null,
  embedding vector(384),
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Create the vector search function
create or replace function match_chunks (
  query_embedding vector(384),
  match_count int default 5
)
returns table (
  id bigint,
  text text,
  similarity float
)
language sql stable
as $$
  select
    chunks.id,
    chunks.text,
    1 - (chunks.embedding <=> query_embedding) as similarity
  from chunks
  order by chunks.embedding <=> query_embedding
  limit match_count;
$$;
```

### 4. Configure Environment Variables
Create a `.env.local` file in the root directory based on `.env.example`:

```bash
cp .env.example .env.local
```

Add your API keys and Supabase credentials to `.env.local`:

```env
# Supabase Configuration
SUPABASE_URL=https://your-project-ref.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

# AI Providers
GROQ_API_KEY=your-groq-api-key
HUGGINGFACE_API_KEY=your-huggingface-api-key
```
*(Note: Do not commit `.env.local` to version control).*

### 5. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the application in action.

## 📂 Project Structure

- `app/` - Next.js App Router pages and API routes (e.g., `/api/chat`).
- `lib/` - Core logic including:
  - `embedder.ts` - HuggingFace API integration for embeddings.
  - `supabase.ts` - Database connection and vector search functions.
  - `chunker.ts` - Logic for chunking documents (PDF text).
  - `rate-limit.ts` - API rate limiting logic.
- `app/components/` - React components for the UI.
